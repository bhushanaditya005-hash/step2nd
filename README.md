# Java Coding Problems — Part A

Solutions to 10 Java coding problems covering strings, arrays, loops, conditionals, number logic, and object-oriented programming.

## Problems

1. `VowelConsonant.java` — Counts vowels and consonants in a word.
2. `PalindromeChecker.java` — Reverses a word with `StringBuilder` and checks whether it is a palindrome.
3. `EvenOdd.java` — Counts even and odd integers.
4. `ArrayReverse.java` — Reverses an array in place using two pointers.
5. `DigitSumReverse.java` — Calculates the sum of digits and reverses a positive integer.
6. `PrimeChecker.java` — Checks whether a number is prime.
7. `Factorial.java` — Calculates the factorial of a non-negative integer.
8. `GradeAssignment.java` — Assigns a grade based on marks.
9. `LeapYear.java` — Determines whether a year is a leap year.
10. `StudentResult.java` — Calculates a student's average and grade using a `Student` class.

## Requirements

- Java JDK installed
- A terminal or IDE such as VS Code

## Compile and run

Open a terminal in this folder. For example, to run Problem 1:

```bash
javac VowelConsonant.java
java VowelConsonant
```

For another problem, use its corresponding filename and class name. Compile and run one program at a time.
